**6th Rank All-India, Ciphathon 2026**

`React` `JavaScript` `Chrome Extension` `Vite`

- Real-time Chrome extension that intercepts and blocks sensitive data leakage in AI prompts before it reaches any server.
- Engineered 75+ regex and entropy-based detection rules across 16 categories (API keys, PII, cloud secrets, connection strings).
- Covers 10+ LLM platforms including ChatGPT, Gemini, and Claude.

## [ClipFrame](https://github.com/unironic-sujal/clipframe) — Video Frame Extractor with Full DevOps Pipeline

`Docker` `Kubernetes` `Terraform` `Ansible` `GitHub Actions` `Nginx`

- Browser-based PWA that extracts lossless PNG frames from any local video (4K/8K/60fps) — runs 100% client-side with zero server contact.
- Full production DevOps pipeline: Docker multi-stage build → Kubernetes (deployment, ingress, HPA) provisioned via Terraform; machine bootstrap via Ansible.
- CI pipeline enforces XSS prevention, CSP headers, secret scanning, and Docker health checks; CD deploys to DockerHub and K8s on merge.

## [NutriScan](https://github.com/unironic-sujal/nutriscan) — Cross-Platform Barcode Nutrition Scanner

`Flutter` `React` `Node.js` `MongoDB` `Docker` `GitHub Actions`

- Cross-platform barcode nutrition scanner with a native Flutter mobile app and React web app.
- Both frontends powered by a unified Node.js/Express REST API backed by MongoDB.
- Containerized with Docker and deployed via GitHub Actions CI/CD to Vercel (frontend) and Railway (backend).
- Implemented MongoDB caching to reduce external API calls to Open Food Facts.
